Rezume.AI

Rezume.AI is an AI-powered resume optimization tool designed to help job seekers tailor their resumes for specific job roles and maximize their chances of passing ATS (Applicant Tracking System) filters and impressing recruiters.

It acts as an intelligent resume expert that analyzes your existing resume against a target job description and generates a fully optimized, job-aligned version of your resume.

🚀 What Rezume.AI Does

Rezume.AI helps you:

Analyze your resume against a target job description
Identify skill gaps, missing keywords, and misaligned experience
Optimize your resume for ATS compatibility
Improve structure, clarity, and professionalism
Rewrite bullet points using strong action verbs and the STAR method (Situation, Task, Action, Result)
Highlight measurable achievements and real impact
Suggest missing skills, certifications, and improvements
🧠 How It Works

Rezume.AI performs a structured evaluation of your resume and:

Compares your resume with the job description
Extracts and prioritizes ATS-friendly keywords
Identifies missing or weak sections
Rewrites and improves content for maximum impact
Produces a fully optimized, role-specific resume
📦 Output You Receive

Rezume.AI returns a complete resume optimization report including:

Resume Analysis Summary — overview of strengths and gaps
Key Improvements Suggested — actionable enhancement points
Optimized Resume — fully rewritten, ATS-friendly version
ATS Keyword Match Score (0–100%) — alignment score with job description
Final Tips — guidance for further improvement
✍️ Writing Standards

All outputs follow strict quality guidelines:

Clean, professional formatting
Concise, high-impact language
No fluff or generic statements
Strong action verbs throughout
Quantified achievements wherever possible
Fully tailored to the target role and industry
ATS-optimized keyword integration
📥 Required Inputs

To generate an optimized resume, provide:

Your current resume (text or document)
The target job description
Optional: industry, role focus, or career preferences
📊 Output Format

Rezume.AI structures every response as:

Resume Analysis Summary
Key Improvements Suggested
Optimized Resume
ATS Keyword Match Score
Final Tips
🎯 Goal

Rezume.AI is built to transform standard resumes into high-performance, job-targeted documents that improve interview chances by aligning closely with recruiter expectations and ATS systems.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/75ba856d-5ce5-41ae-9875-cf7b3054a8c9

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
